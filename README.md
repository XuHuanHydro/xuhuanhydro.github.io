# Huan Xu — Academic Website

Source for [xuhuanhydro.github.io](https://xuhuanhydro.github.io), built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template and hosted by GitHub Pages.

The public site contains verified profile information and a Scholar-sourced publication list. Research, Software, and CV remain hidden until their content is ready.

See the detailed Chinese guide, [SITE_MAINTENANCE.md](SITE_MAINTENANCE.md), for site-specific editing, uploads, local preview, deployment, rollback, and security checks.

## Deployment

GitHub Pages publishes the repository's `main` branch from `/ (root)` using GitHub's native Jekyll build and deployment workflow. Deployment status is available in [Actions](https://github.com/XuHuanHydro/xuhuanhydro.github.io/actions).
